💡 PETUNJUK MENJALANKAN SETELAH MENGUNDUH

🪟 Pengguna Windows

Jalankan file Envku_1.4.5_x64-setup.exe. Setelah terpasang, klik kanan ikon aplikasi lalu pilih Run as Administrator agar dapat mengelola Windows Services (Apache & MySQL) dan file hosts secara lancar.

🐧 Pengguna Linux

Untuk AppImage, berikan izin eksekusi:
chmod +x envku_*.AppImage lalu klik ganda. Untuk paket Debian/Ubuntu:
sudo dpkg -i envku_*.deb. Akses root diminta via dialog sandi native (PolicyKit).

🚀 Langkah Pertama di Aplikasi

Buka tab Downloader pada menu kiri untuk mengunduh dan mengekstrak komponen Apache 2.4, MySQL 8.0, PHP, phpMyAdmin, atau Redis secara portabel ke C:\server dalam 1-klik.
