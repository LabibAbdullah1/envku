EKOSISTEM & FITUR UTAMA

Semua komponen server dan alat bantu pengembangan lokal lengkap dalam satu aplikasi portable yang super cepat.

PHP 8.2 & 8.3

PHP VERSION SWITCHER

Ganti versi modul PHP di Apache dan PATH CLI Windows secara instan (dukungan PHP 8.2 hingga 8.5) tanpa mengganggu konfigurasi utama.

VHOST

PROJECT & PROXY WIZARD

Buat Virtual Host domain lokal (.test) untuk PHP/HTML atau Reverse Proxy otomatis ke port Node.js/Vite secara mudah.

SVC

SERVICE CONTROL PANEL

Kendalikan dan daftarkan Apache 2.4 & MySQL 8.0 langsung sebagai Windows Services yang terisolasi dalam 1-klik.

NVM

NODE.JS & NVM INTEGRATION

Kelola beberapa versi Node.js secara global di komputer Anda menggunakan integrasi NVM bawaan yang praktis.

MYSQL

MYSQL 8.0 PORTABLE

Database MySQL terisolasi di direktori C:\server dengan akun root lokal tanpa password untuk pengujian serba cepat.

PMA

PHPMYADMIN v5.2.3

Antarmuka pengelola basis data MySQL dengan skema relasional pmadb yang sudah terkonfigurasi otomatis bebas error.

REDIS

REDIS CACHE v5.0

Engine database memori (redis-server.exe) berkinerja tinggi untuk pengujian session storage, caching, dan queue worker.

MAIL

MAILPIT SMTP SANDBOX

Server SMTP lokal (port 1025) dan dashboard webmail (port 8025) untuk menguji pengiriman email tanpa terkirim ke alamat asli.

CMP

PHP COMPOSER GLOBAL

Dependency manager PHP (composer.phar) terintegrasi otomatis untuk memasang library PHP via terminal lokal.

KEUNGGULAN UTAMA

MENGAPA MEMILIH ENVKU?

Dirancang khusus untuk pengembang web modern yang membutuhkan server lokal instan tanpa bloatware dan konfigurasi rumit.

🚀 100% Portabel & Bebas Registry

Semua file dan data server terpusat di satu folder. Tidak menyentuh Windows Registry, mudah dipindahkan atau dicadangkan kapan saja.

⚡ Sangat Ringan Berbasis Rust

Dibangun dengan Tauri v2 dan Rust. Konsumsi RAM hanya belasan megabyte, jauh lebih hemat baterai dan memori dibanding Electron.

🐘 Multi-PHP Switcher 1-Klik

Ganti versi PHP secara instan tanpa restart sistem atau modifikasi manual httpd.conf. Cocok untuk proyek lawas maupun mutakhir.

🔒 Terisolasi & Tanpa Konflik

Apache, MySQL, Redis, dan Mailpit berjalan dalam konfigurasi terisolasi sehingga tidak akan merusak layanan lain di komputer Anda.

CARA MEMULAI

1

Unduh Aplikasi

Unduh file installer sesuai dengan OS Anda: `.exe` untuk Windows atau `.deb`/`.AppImage` untuk Linux di halaman unduhan.

2

Jalankan dengan Hak Akses Tinggi

Di Windows, klik kanan aplikasi lalu pilih Run as Administrator. Di Linux, aplikasi otomatis meminta akses administrator melalui dialog sandi native (PolicyKit/`pkexec`) saat diperlukan.

3

Mulai Unduh Komponen

Buka tab Downloader untuk memasang Apache, PHP, MySQL, Composer, Redis, Mailpit, atau phpMyAdmin ke direktori folder server pilihan Anda secara otomatis.
